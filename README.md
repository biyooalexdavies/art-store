# Art Collection Manager

A clean, minimalist art collection catalog app built with pure HTML, CSS, and modern JavaScript.

## Features
- **Client-Side Persistence**: Saves all artwork records directly in browser `localStorage`.
- **Image Upload & Optimization**: Supports drag-and-drop or file upload for artwork photos, with automatic client-side canvas optimization to preserve storage space.
- **Full Catalog Fields**: Title, Artist, Type, Medium, Size, Year, and Availability Status (*In Stock* / *Sold Out*).
- **Search & Filter**: Real-time instant search across titles, artists, mediums, and types, along with availability filtering.
- **CRUD Operations**: Add, Edit, and Delete (with confirmation dialog).
- **Mobile Responsive**: Fully responsive layout optimized for mobile phones, tablets, and desktops.
- **Zero Server Setup**: Runs entirely in any web browser without dependencies, builds, or servers.

## Quick Start
Open `index.html` directly in your browser.
